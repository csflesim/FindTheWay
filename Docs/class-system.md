# 學員管理系統規劃文件

## 概覽

本專案分為兩個獨立的前端入口：

| 入口 | 路徑 | 說明 |
|------|------|------|
| 展示網站 | `findtheway.com/` | 現有的品牌官網 |
| 會員專區 | `findtheway.com/m` | 手機版學員管理系統（Mobile-first） |
| 教師專區 | `findtheway.com/m/teacher` | 手機版教師管理系統（Mobile-first） |
| 管理後台 | `findtheway.com/sys-admin` | 課程、券、學員、訂單的後台管理介面 |

## 帳號與身份架構

### 帳號類型

一個帳號的身份可以同時是**會員**與**學生**，並非互斥。

| 身份 | 說明 |
|------|------|
| 會員 (Member) | 主帳號持有人，可管理學生、購買課堂券 |
| 學生 (Student) | 實際上課的人，可掛在主帳號下，也可以是主帳號本人 |

### 一帳號多學生

類似 trip.com 旅客管理邏輯：  
- 一個主帳號可以新增並管理多位學生
- 主帳號可以代替任一名下學生購買課堂券、報名課程
- 學生本身不需要獨立帳號

```
主帳號 (Member)
├── 本人 (也可以是學生)
├── 學生 A
├── 學生 B
└── 學生 C
```

## 課堂券系統

### 購買流程

```
購買課堂券組合 → 持有券包 → 進入指定課程報名 → 抵用課堂券 → 完成報名
```

> 購買券後**不等於**報名課程，還需要主動到每堂課程頁面報名並抵用。

### 課堂券組合設定（後台）

每一個「課堂券組合」可以設定以下參數：

| 欄位 | 說明 |
|------|------|
| 組合名稱 | 例：「10堂體驗包」、「單堂試課」 |
| 堂數 (quantity) | 一個 set 內含多少堂課的抵用次數 |
| 價格 | 組合售價 |
| 可轉讓 (transferable) | 是否允許將券轉讓給其他帳號下的學生 |
| 有效期限 | 券的使用期限（可選） |

### 課堂券狀態

| 狀態 | 說明 |
|------|------|
| 未使用 | 購入後尚未抵用 |
| 已抵用 | 已報名特定課程並扣除 |
| 已轉讓 | 轉讓給其他學生（僅限可轉讓券） |
| 已過期 | 超過有效期限 |

## 核心功能模組

### 前台（`/m`，會員專區）

- [ ] 登入 / 註冊
- [ ] 管理名下學生（新增、編輯、刪除）
- [ ] 查看課堂券餘額（依學生分類）
- [ ] 瀏覽課程列表
- [ ] 以課堂券報名課程
- [ ] 查看課程預約紀錄

### 後台（Admin）

- [ ] 課堂券組合管理（建立 / 編輯 / 上下架）
- [ ] 訂單管理
- [ ] 學員列表與購券紀錄
- [ ] 課程建立與場次管理
- [ ] 報名名單管理

## 前台頁面結構（`/m`）

底部固定導覽列 4 tab：`首頁` | `課程` | `訂單` | `我的`

---

### `/m` 首頁

- 頂部 header：品牌名稱 + 登入 / 註冊按鈕
- Hero banner（黑底）：工作坊名稱、登入引導 CTA
- 課程分類 tab 橫向滑動：全部 / 素描 / 水彩 / 油畫 / 兒童美術 / 親子
- 近期課程卡片列表：封面圖佔位、年齡標籤、堂名、時間、剩餘名額、價格

---

### `/m/courses` 課程列表

- 頂部分類 tab 篩選
- 課程卡片（大圖版）：封面圖 + 年齡標籤、講師、時間、剩餘名額、報名按鈕

---

### `/m/orders` 訂單 & 課堂券

- 課堂券餘額卡片（黑底）：學生姓名、組合名稱、剩餘堂數 / 總堂數、到期日、可 / 不可轉讓標籤
- 報名紀錄列表：課程名稱、時間、學生、狀態（已報名 / 已完成）

---

### `/m/profile` 我的

- Profile card（淺灰底）：頭像、帳號名稱、Email、課堂券總餘額、名下學生數、已完成課程數
- 快速操作 4 格：購買課堂券 / 管理學生 / 報名課程 / 出席紀錄
- 名下學生橫向卡片列表：頭像、姓名、年齡、剩餘堂數、+ 新增按鈕
- 功能選單：我的學生 / 購買課堂券 / 轉讓課堂券 / 帳號設定

---

## UI 設計規範（`/m`）

- 背景色：`#fafaf9`（暖白）
- 卡片背景：`#ffffff`，邊框 `#f0f0f0`
- 次要文字：`#999`，分隔線 `#f5f5f5`

- 底部 nav 高度預留 `pb-20`，安全區域 inset 處理
