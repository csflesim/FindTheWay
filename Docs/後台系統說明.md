# 忙碌不迷路藝術工作坊 — 後台系統說明

> 最後更新：2026/08/09。技術棧：Next.js App Router + Supabase（Postgres / Auth / Storage），部署於 Vercel。
> 本文件描述管理後台（`/sys-admin`）的完整功能、資料模型與核心業務流程。

---

## 一、系統總覽

系統分三個端口，**帳號完全獨立**（一人可在三端各有身分，Email／電話／LINE ID 為聯絡資料、可跨表重複）：

| 端口 | 路徑 | 使用者 | 登入方式 |
|------|------|--------|----------|
| 會員前台 | `/m` | 會員（role=member） | LINE 註冊（Email 驗證後建帳號）；電話/Email＋密碼；LINE 快捷 |
| 教師專區 | `/m/teacher` | 教師（role=teacher，專屬帳號 `teacher-<ID>@login.findtheway.app`） | Email/電話＋教師密碼；LINE 快捷 |
| 管理後台 | `/sys-admin` | 後台人員（role=staff/admin，`帳號@findtheway.com`） | 帳號/Email/電話＋密碼；LINE 快捷 |

- 統一登入 API `/api/auth/portal-login`：輸入的識別（電話/Email/帳號）只是**查該端自己的表**的鍵，找到後以該身分的專屬帳號驗密碼，最後驗證角色與端口相符。
- LINE 登入以 `?portal=member|teacher|staff` 分流；LINE ID 端內唯一，三端可綁同一個 LINE。
- 守門三層：proxy（路由）、API guard（`requireStaff` / 授課教師比對）、資料庫 RLS（`is_staff()`）。

### 後台版面

黑色側欄（可收合成圖示欄）＋白色頂欄（麵包屑、通知鈴鐺、姓名＋頭像下拉:個人設定／登出）。

## 二、核心業務模型：訂單歸訂單、券歸券

**訂單只管金流**（買券包、買單堂），**券管上課資格**。

### 券的狀態機

```
發券 → 未使用 ⇄ 待使用（綁定課程＋日期）→ 已使用
          ↓
        已失效（售後收回）
```

| 轉移 | 觸發 | 規則 |
|------|------|------|
| 發券 | 後台確認付款 | 效期＝付款日＋商品有效月數；單堂直購發券後立即綁定 |
| 報名（未使用→待使用） | 會員選課＋日期 | 券種在課程允許清單、未過期、該堂名額未滿；立即生效 |
| 取消上課（待使用→未使用） | 會員 | 限上課前 N 小時（商品 `cancel_hours`）；過期券鎖死不可取消 |
| 核銷（待使用→已使用） | 點名標「出席」或「缺席」 | 缺席照扣（未依期限取消視同使用） |
| 延期退回（→未使用） | 點名標「延期」 | 券解綁退回，可重新預約 |
| 失效 | 售後收回 | 只有「未使用」能收回 |

- **換課／改期**＝取消上課＋重新報名，無獨立功能。
- **轉讓**：限「未使用＋未過期＋商品開放轉讓」，只能轉給自己名下已核准學員。
- **過期規則**：未使用＋過期＝棄權（不能報名/轉讓/售後）；待使用＋過期＝資格保留但鎖死只能出席。後台皆可「人工延期」救回（以天數累加，不可能倒退）。
- **歷程**：每張券 `history` jsonb 記錄全部事件（發券/報名/取消/核銷/轉讓/人工操作），每筆含時間與**異動者**（名字＋身分）。

### 商品「單堂」型別

- 商品分「券包」與「單堂」（堂數鎖定 1）。
- 內部課程的「可使用課堂券」**必須含至少一個單堂商品**——它就是該課的直購定價（課程本身的 price 欄位已退役，僅作後備）。
- 前台列表/詳情顯示的單堂價、直購金額（×堂數）都取自此商品。

### 報名與點名

- 內部課程**每一堂都要報名**（用券即綁或直購）；週期課報名時選日期（預設列 4 堂可展開至 8 堂），名額按堂計算，已預約的日期鎖定不可重選。
- 直購訂單「待確認」期間不佔名額；確認付款時若該堂已滿會擋下。
- 點名名冊＝綁定該堂的券（持有人＋券號）；外部課程純點名不碰券。
- 課程 `enrolled` ＝未來場次仍綁定中的券數（`syncCourseEnrollment`）。

## 三、後台模組一覽

### 總覽（`/sys-admin`）
營運儀表板：即將開課、待辦摘要。

### 人員管理
| 頁面 | 功能 | 主要資料表 |
|------|------|-----------|
| 會員管理 `/accounts` | 會員清單、LINE 帳號標示、基本編輯 | `profiles`（role=member）＋ auth |
| 學員管理 `/students` | 會員名下學員審核（待審/已核准）、內外部類型 | `students` |
| 教師管理 `/teachers` | 教師檔案 CRUD、**建立/重設教師登入帳號**（專屬帳號＋密碼）、課表檢視 | `teachers`、`/api/admin/teacher-account` |

### 課程管理
| 頁面 | 功能 | 主要資料表 |
|------|------|-----------|
| 單位管理 `/units` | 外部合作單位（含子單位 jsonb） | `units` |
| 教室管理 `/classrooms` | 教室與設備、教室課表 | `classrooms` |
| 課堂管理 `/courses` | 課程 CRUD（內/外部複選、班表:固定週期**多星期複選**或單堂課、可使用課堂券=商品 id 複選且強制含單堂、隱藏＝不上列表但**課程連結**可達）、**點名**（選擇課堂日期→綁定券名冊→出席/延期/缺席） | `courses`、`course_teachers`、`course_attendance` |
| 線上課程 `/online-courses` | 線上課＋章節（YouTube） | `online_courses`、`online_sections` |
| 出席管理 `/roster` | 各課程出席總表 | `course_attendance` |

### 經營管理
| 頁面 | 功能 | 主要資料表 |
|------|------|-----------|
| 商品管理 `/tickets` | 課堂券組合 CRUD：型別（券包/單堂）、堂數、售價、有效月數、取消期限、可轉讓、上下架 | `products` |
| 訂單管理 `/orders` | 訂單清單、後台代下單、**確認付款**（發券＋單堂自動綁定＋工作流觸發）、取消 | `orders`、`/api/orders/confirm` |
| 售後管理 `/aftersales` | 收回未使用券（設已失效）、退款金額、售後紀錄 | `orders.after_sales`、`tickets` |
| 卡券管理 `/vouchers` | 全部券的清單（狀態/綁定/效期/**最後異動者**）、券詳情:歷程時間軸＋**人工延期（天數）**＋**退回未使用** | `tickets`、`/api/admin/ticket-action` |
| 帳務管理 `/finance` | 由訂單即時推導:收入/退款/待收款/課券均攤 | `orders` |

### 訊息通知管理
| 頁面 | 功能 |
|------|------|
| 訊息管理 `/messages` | Email/LINE Flex 模板設計器（可插入變數:學員姓名、課程、日期、**訂單連結、課程連結**…）、模擬發送 |
| 訊息工作流 `/line-workflows` | 事件觸發流程（付款成功、報名確認…）→ 真實發送 Email/LINE，記入 `message_logs` |

### 展示管理
手機版廣告圖 `/display/mobile-banner`：前台輪播 banner。

### 系統管理
| 頁面 | 功能 |
|------|------|
| 人員管理 `/system/members` | 後台人員/教師/管理員帳號 CRUD 與角色指派 |
| 角色管理 `/system/roles` | 角色權限矩陣（唯讀說明；RLS 強制） |
| 參數管理 `/system/params` | LINE Login/Messaging、SMTP（密碼 AES-256-GCM 加密入庫）、付款方式、功能開關、上課時間 |
| 個人設定 `/system/account` | （右上角頭像進入）聯絡電話/Email（登入查表鍵）、LINE 綁定、改密碼 |

## 四、API 清單

| 分類 | Route | 用途 |
|------|-------|------|
| 認證 | `/api/auth/portal-login` | 三端統一登入（查表→專屬帳號驗密碼→驗角色） |
| | `/api/auth/line`（+`/callback`） | LINE OAuth（portal 分流／whoami 綁定模式；回呼網址由請求網域動態推導） |
| 會員 | `/api/member/email-code`、`verify-email` | LINE 註冊的 Email 驗證碼（通過才建帳號） |
| | `/api/member/book`、`cancel-booking` | 用券報名（綁定）／取消上課 |
| | `/api/member/transfer-tickets` | 轉讓課堂券 |
| | `/api/member/line-binding` | 會員 LINE 綁定/解綁 |
| 教師 | `/api/teacher/me` | 教師身分解析（僅認專屬帳號） |
| | `/api/teacher/profile` | 個人資料 PATCH／LINE 綁定 PUT/DELETE |
| 點名 | `/api/attendance/roster`、`save` | 名冊查詢／點名儲存（核銷/退回） |
| 後台 | `/api/orders/confirm` | 確認付款（發券＋綁定＋名額檢查＋工作流） |
| | `/api/admin/ticket-action` | 券人工延期（天數）/回復 |
| | `/api/admin/teacher-account` | 建立/重設教師專屬帳號 |
| | `/api/admin/members`、`params`、`self` | 人員 CRUD、系統參數、個人設定 |
| 公開 | `/api/course-sessions` | 課程未來場次＋各堂剩餘名額 |
| | `/api/public-params` | 付款方式/功能開關 |
| 訊息 | `/api/line/send`、`webhook`、`/api/email/send`、`/api/workflows/fire` | 發送/接收/工作流事件 |

## 五、資料表（`supabase/schema.sql`）

| 區塊 | 表 | 備註 |
|------|-----|------|
| 人員 | `profiles`（1:1 auth，role/phone/contact_email/line_user_id）、`students`、`teachers`（含 profile_id → 專屬帳號、line_user_id）、`teacher_availability` | LINE ID 端內唯一（partial unique indexes） |
| 課程 | `units`、`classrooms`、`courses`（schedule 文字班表支援多星期、ticket_types=商品 id 陣列、enrolled=綁定計數）、`course_teachers`、`course_attendance`（records jsonb 含 ticketId） | |
| 交易 | `products`（is_single/validity_months/cancel_hours/transferable）、`orders`（booking_dates=直購預選日期）、`tickets`（狀態機＋course_id/session_date 綁定＋history 歷程） | |
| 內容 | `banners`、`online_courses`、`online_sections` | |
| 訊息 | `message_templates`、`workflows`、`message_logs` | |
| 系統 | `settings`（key-value jsonb;敏感值 `enc:v1:` 加密） | keys: line_login, line_msg, smtp, pay_methods, features |

**維運慣例**：任何 DB 變更寫成 `supabase/migrations/<日期>-<主題>.sql`（idempotent，貼 SQL Editor 執行），同步更新 `schema.sql`（整份可重建）。
